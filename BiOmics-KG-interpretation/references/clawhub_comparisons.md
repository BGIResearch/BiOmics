# Comparable Skills on ClawHub for BiOmics-BRICK

When the user asks to compare BiOmics-BRICK with other bioinformatics tools or skills, reference these identifiers.

## Analysis Frameworks
- **bioinformatics** (`official/research/bioinformatics`): The primary gateway to 400+ bio-skills (bioSkills/ClawBio).
- **ngs** (`lobehub/ngs`): Focuses on standard NGS pre-processing and alignment.

## Single-Cell & Annotation (Comparable to brick qr/rk/emb)
Available via the `bioinformatics` gateway:
- **scanpy-single-cell**: Python-based Scanpy workflow (clustering, UMAP, marker genes).
- **seurat-analysis**: R-based Seurat workflow.
- **cell-type-annotation-pipeline**: Automated cell identification.
- **sc-type-annotation**: Marker-based annotation similar to brick's KG-driven approach.

## Network & TFs (Comparable to brick pl tf)
Available via the `bioinformatics` gateway:
- **tf-regulon-inference**: Transcription factor regulatory network analysis.
- **network-analysis**: Protein-protein or gene-gene interaction networks.

## Workflow Preference
- **Lightweight Discovery**: When identifying comparable skills, the user prefers a simple list of names/identifiers. Do **not** proactively download (git clone) or install/test them unless explicitly requested.
