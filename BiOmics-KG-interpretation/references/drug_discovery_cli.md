# Drug discovery with the `brick` CLI

This recipe is the CLI translation of the package's Drug Discovery workflow:
derive a prespecified state-associated gene union, query its one-hop KG
neighbors, retain enriched paths, build the native cell/gene/KG graph, learn a
GRACE embedding, and rank Chemical nodes by cosine similarity to one exact
Disease anchor.

The CLI owns KG querying, enrichment, graph construction, GRACE fitting,
ranking freeze, and post-freeze validation. Dataset subsetting and Scanpy DEG
remain a small, auditable Python preprocessing step because `brick workflow
drug` does not define the biological subset.

## Source-method mapping

| Scientific operation | CLI implementation | Locked behavior |
|---|---|---|
| State-associated genes | Scanpy preprocessing, then `--genes` | `rank_genes_groups(..., groupby="Ventilated")`; top 100 per returned state; union |
| One-hop Gene neighbors | `brick qr` generated by `brick workflow drug` | Target-type union; stable KG IDs retained |
| Path enrichment | `brick rk --enrich` | Exact KG-wide relation backgrounds; raw `p < 0.0001` |
| Joint graph | `brick drug build-graph` | Native graph only; no injected nodes or synthetic edges |
| GRACE | `brick-gpu drug grace-rank` | One prespecified seed and 1000 epochs for source-run parity; CUDA is a runtime adaptation |
| Chemical ranking | `brick-gpu drug grace-rank` | Raw cosine similarity to the exact `COVID-19` Disease node |
| Reference comparison | `brick qr` plus `brick drug validate` | Query only after ranking freeze; evaluation-only |

Do not add a full-atlas cell-type DEG stage to the NK workflow. The source
method starts from a cell-type-specific object and performs only the
`Ventilated` state comparison. Adding another DEG union materially changes the
query universe and graph size.

## 1. Prepare the NK input and primary gene union

The input atlas is already processed. Do not normalize, log-transform, scale,
or otherwise mutate expression values unless an input audit proves that the
required representation is absent.

```python
from pathlib import Path

import scanpy as sc

adata = sc.read_h5ad(
    "data/Single_cell_atlas_of_peripheral_immune_response_to_SARS_CoV_2_infection.h5ad"
)

required_obs = {"cell_type_fine", "Ventilated"}
missing = sorted(required_obs.difference(adata.obs.columns))
if missing:
    raise ValueError(f"Missing required obs columns: {missing}")

nk_mask = adata.obs["cell_type_fine"].astype(str).eq("NK")
if not nk_mask.any():
    raise ValueError("No cells with cell_type_fine == 'NK'")

adata_nk = adata[nk_mask].copy()
if adata_nk.obs["Ventilated"].astype(str).nunique() < 2:
    raise ValueError("NK subset has fewer than two Ventilated states")

sc.tl.rank_genes_groups(adata_nk, "Ventilated")
ranked = adata_nk.uns["rank_genes_groups"]["names"]
groups = list(ranked.dtype.names)
top_genes = {
    group: [str(g) for g in ranked[group][:100] if str(g) not in {"", "nan", "None"}]
    for group in groups
}
gene_union = sorted({gene for genes in top_genes.values() for gene in genes})
if not gene_union:
    raise ValueError("The primary gene union is empty")

adata_nk.write_h5ad("nk_primary.h5ad")
Path("primary_gene_union.txt").write_text("\n".join(gene_union) + "\n")
```

Record input shape, NK shape, state counts, the returned group order, every
per-state top-100 list, and the final union. Do not silently replace gene IDs.

## 2. Generate and inspect the GRACE workflow

Use these locked parameters for an NK adaptation of the source workflow:

```bash
brick workflow drug \
  --genes primary_gene_union.txt \
  --adata nk_primary.h5ad \
  --method grace \
  --target-types Disease,Phenotype,Process,Cell_Component,Pathway,Function,Tissue,Cell,Chemical,Stage \
  --anchor-disease COVID-19 \
  --query-limit 500 \
  --pvalue-cutoff 0.0001 \
  --grace-seeds 20241204 \
  --grace-epochs 1000 \
  --evaluation-only \
  --agent-plan \
  -o brick_drug_run
```

Then validate the generated plan before execution:

```bash
brick agent check-plan -p brick_drug_run/agent_plan.json
brick agent run -p brick_drug_run/agent_plan.json
brick agent run -p brick_drug_run/agent_plan.json --execute --max-retries 1
```

The public `brick qr` CLI accepts an integer row limit; it does not expose an
unlimited/`None` mode. Therefore `500` is an explicit implementation boundary,
not a claim that all KG rows were retrieved. Record per-target row counts and
possible boundary hits. Do not quietly increase the limit after viewing
reference overlap.

The generated workflow is expected to include the following scientific chain:

```bash
# One brick qr call for each prespecified target type, using
# brick_drug_run/geneset.txt, followed by:
brick plan merge-csv -o brick_drug_run/combined_query.csv brick_drug_run/query_*.csv

brick rk \
  -i brick_drug_run/combined_query.csv \
  --enrich \
  --background-method auto \
  --pvalue-cutoff 0.0001 \
  --relation-batch-size 10 \
  --relation-workers 4 \
  --relation-retries 2 \
  -o brick_drug_run/native_enrichment_all.csv

brick drug filter-enrichment \
  -i brick_drug_run/native_enrichment_all.csv \
  --pvalue-cutoff 0.0001 \
  -o brick_drug_run/native_enrichment_p1e-4.csv

brick drug build-graph \
  -a nk_primary.h5ad \
  --genes primary_gene_union.txt \
  -i brick_drug_run/native_enrichment_p1e-4.csv \
  --disease COVID-19 \
  --pvalue-cutoff 0.0001 \
  --identity-output brick_drug_run/primary_joint_graph_nodes.csv \
  --audit-output brick_drug_run/primary_joint_graph_audit.json \
  -o brick_drug_run/primary_joint_graph.graphml

brick-gpu drug grace-rank \
  -g brick_drug_run/primary_joint_graph.graphml \
  --identity brick_drug_run/primary_joint_graph_nodes.csv \
  --disease COVID-19 \
  --seeds 20241204 \
  --epochs 1000 \
  --device cuda \
  -o brick_drug_run
```

Use `brick plan merge-csv`; shell concatenation can repeat CSV headers as data
rows.

## 3. Exact enrichment is mandatory

`--background-method auto` is acceptable only when the enrichment audit shows
an exact KG-wide relation background, such as the Cypher or exact-relation
route. The following is not source-method parity and must stop the run:

- `query_subset_degraded` or any query-result-only denominator;
- a substituted p-value threshold;
- dropping relations because the exact background is slow;
- labeling a partial query universe as KG-wide.

The strict table must be nonempty and every retained row must satisfy raw
`path.2.enrich_pvalue < 0.0001`. Keep the unfiltered enrichment table, strict
table, method audit, and row counts.

## 4. Graph and anchor invariants

Before fitting, verify and save:

- graph node/edge counts and per-type node counts;
- input gene count and matched gene count;
- unique stable IDs for every Chemical and Disease node;
- exactly one graph node labeled `COVID-19` with type `Disease`;
- the exact retained path table used by `build-graph`.

If the Disease anchor is absent or duplicated, stop. Never repair the graph by
inserting a standalone COVID-19 node, adding synthetic edges, or borrowing a
node from the later reference query.

## 5. GRACE runtime contract

Run the package model on CUDA with one seed (`20241204`) for 1000 epochs. Save
the full loss trace, embeddings, per-node identity table, Chemical ranking,
runtime audit, and frozen-ranking hash. The GPU requirement is an execution
adaptation; the scientific graph, loss, and raw cosine ranking remain the
package workflow.

Before the full fit, require a lightweight task-local graph smoke run to pass
through the same launcher, for example the same native graph with one epoch in
a separate `smoke/` output directory:

```bash
brick-gpu drug grace-rank \
  -g brick_drug_run/primary_joint_graph.graphml \
  --identity brick_drug_run/primary_joint_graph_nodes.csv \
  --disease COVID-19 \
  --seeds 20241204 \
  --epochs 1 \
  --device cuda \
  -o brick_drug_run/smoke
```

This smoke run verifies CUDA and the package `GRACE_model` import by actually
executing the same package path. Do not use its embedding or ranking as a
primary result.

If DGL/GraphBolt is incompatible with the installed PyTorch runtime, use only
the task-local compatibility mechanism supplied by the skill/runtime. Do not
replace package versions or install a fake global `dgl` package.

## 6. Freeze before reference validation

The primary Chemical order is descending raw cosine similarity between each
Chemical embedding and the exact Disease-anchor embedding. Stable KG IDs are
the identity key; labels are display fields. Freeze and hash the complete
ranking before any reference query.

Only after the hash exists, run the configured Disease-to-Chemical query for
`COVID-19` with relation `pharmaco_effect_on`, preserve the complete returned
table, and validate the frozen ranking:

```bash
brick qr COVID-19 \
  --st Disease \
  --tt Chemical \
  -r pharmaco_effect_on \
  -n 500 \
  -o brick_drug_run/covid_chemical_reference.csv

brick drug validate \
  --ranking brick_drug_run/primary_chemical_ranking.csv \
  --reference brick_drug_run/covid_chemical_reference.csv \
  --freeze brick_drug_run/ranking_frozen.sha256 \
  --cutoffs 10,25,50 \
  --identity-audit brick_drug_run/chemical_identity_audit.csv \
  -o brick_drug_run/ranking_validation.csv
```

Report label-level and stable-ID-level overlap separately. A valid zero-row
reference result must still be a parseable CSV with headers; a one-byte or
schema-less file is an execution failure, not evidence of no overlap.

## 7. Notebook execution QA

Notebook QA must reopen the saved notebook after execution and derive status
from its contents. Counting nonempty code cells is not an execution check.

```python
import nbformat

nb = nbformat.read(notebook_path, as_version=4)
code_cells = [cell for cell in nb.cells if cell.cell_type == "code"]
counts = [cell.execution_count for cell in code_cells]
error_outputs = [
    output
    for cell in code_cells
    for output in cell.get("outputs", [])
    if output.get("output_type") == "error"
]

qa = {
    "code_cell_count": len(code_cells),
    "executed_cell_count": sum(count is not None for count in counts),
    "error_output_count": len(error_outputs),
    "executed_top_to_bottom": (
        bool(code_cells)
        and all(count is not None for count in counts)
        and counts == sorted(counts)
        and len(set(counts)) == len(counts)
    ),
}
qa["status"] = "pass" if (
    qa["executed_cell_count"] == qa["code_cell_count"]
    and qa["error_output_count"] == 0
    and qa["executed_top_to_bottom"]
) else "fail"
```

Never hardcode QA values or generate a pass report independently of the
executed notebook.

## Hard stops

Stop and report the concrete blocker if any of these occurs:

- required input columns or NK/state groups are absent;
- the KG query or exact background is unavailable;
- strict enrichment is empty;
- the exact Disease anchor is absent or non-unique;
- CUDA or the package GRACE import fails;
- graph construction or the 1000-epoch run cannot complete without changing
  the locked scientific parameters;
- ranking is not frozen before validation;
- the saved notebook fails the content-derived execution QA.

Do not convert any hard stop into a successful run by changing thresholds,
backgrounds, node sets, epochs, or QA fields.
